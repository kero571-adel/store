# Getting Started with Create React App

## Project Description

This is a React-based e-commerce store application that provides a modern, interactive shopping experience. The application features a product catalog with browsing capabilities, a shopping cart system, user account management, wishlist functionality, and a complete checkout process. It includes multiple pages such as Home, Shop, About, Contact, and Account management, along with various modals for enhanced user interactions.

## Technologies Used

- **React** - JavaScript library for building user interfaces
- **Context API** - State management for global application state
- **CSS** - Styling and responsive design
- **Create React App** - Project scaffolding and build tools

## Features

- 📦 Product catalog with 16+ items
- 🛒 Shopping cart management
- ❤️ Wishlist/Heart list functionality
- 👤 User account management
- 📝 Contact and About pages
- 🎨 Responsive design with image assets
- 📱 Modal dialogs for user interactions
